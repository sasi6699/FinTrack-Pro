Smart Personal Finance Dashboard
===========================================

Programming Language:

Streamlit

SQLite

Libraries:
- Streamlit
- Pandas
- Plotly
- Matplotlib
- SQLAlchemy

Project Description:
FinTrack Pro is a web-based Smart Personal Finance Dashboard developed using Python and Streamlit. The system enables users to register, log in, manage income and expenses, import CSV files, monitor budgets, generate financial reports, and analyze spending habits through interactive charts and dashboards.
